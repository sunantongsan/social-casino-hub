# Island Hub visual patch 0.3.2

Original vector/CSS artwork inspired by the supplied tropical social-game reference: turquoise sea, palm-framed lobby, glass game medallions, colored name ribbons, gold chip controls, emerald felt tables and cream gift panels. All six existing games route from the lobby. Test chip refill, gifts, wager selection and house rules remain functional. No fake daily reward or mission buttons were added.

Mobile layout uses two game columns and stacks a compact chip/rate bar above the table. Wider screens use three game columns and a table-side wallet. Playing cards have rank corners, central suits and a gold selected state. Rummy seats use distinct illustrated avatars and retain opponent card backs. Result headings and payout rows are emphasized. Native compatibility remains 102; content version is 0.3.2.

Validation: production build and existing 31 server/render tests. Browser visual validation was blocked: the cloud browser cannot access the local development server and disallows file URLs. Physical-device visual checks remain required. This patch does not change server economy/game rules.
